# 菠萝粤语精听

粤语播客精听台。为粤语学习者做的 Obsidian 插件：**每句自动标粤拼**、逐句字幕跟随、点字查义、跟读录音、生词本、错题本、打卡统计与笔记沉淀。

## 和英文版的区别

| | 菠萝英语精读 | 菠萝粤语精听 |
|---|---|---|
| 字幕 | 逐句英文 | 逐句粤语 + **自动粤拼（Jyutping）** |
| 查词 | 点单词 → 音标/英释 | 中文无空格，用词典最长匹配切词 → 粤拼 + 普拼 + 英释 |
| 发音 | 系统 TTS | 没有粤语 TTS，靠粤拼 + 原声跟读 |
| 转写 | Whisper（12 倍速） | SenseVoice（支持粤语 yue，约 10 倍速） |
| 图标 | 🎧 headphones | 🌐 languages |

## 装法

**推荐：社区插件市场** —— Obsidian → 设置 → 第三方插件 → 浏览 → 搜 `Pineapple Cantonese Listening` → 安装并启用。首次审核通过、目录同步后即可搜到；在此之前可用下面的手动安装，或用 BRAT 填仓库地址公测。

**手动安装**

1. 从 Release 下载 `main.js`、`manifest.json`、`styles.css` 三件，放进 `你的库/.obsidian/plugins/pineapple-cantonese/`（或解压整个 zip 包）
2. Obsidian → 设置 → 第三方插件 → 关闭「限制模式」→ 刷新 → 打开「菠萝粤语精听」
3. 左侧栏出现语言图标，点开即用

> 市场安装只下载上述三件套，**粤语词典已内联在 `main.js` 里，点字查义开箱即用**；本地转写 / 发音等可选增强见「网络、权限与可选增强」章节。

目录结构必须是 `.obsidian/plugins/pineapple-cantonese/main.js`，多套一层文件夹会认不到。

## 怎么用

1. 打开一集 → 自动找现成逐字稿 → 每句下面标粤拼
2. **单击句子**＝从这句播放；**双击字词**＝查粤拼、普拼、释义 → 一键进生词本
3. **听发音**：双击字词听单个词的粤语发音，或点句子右侧 🔊 听整句——走 edge-tts 的港式粤语音色（`zh-HK-HiuGaai` / `WanLung`），和粤拼一致
4. 听不清就开「**单句循环**」，反复磨一句；想连续听就开「**自动连播**」，句尾自动进下一句（两者互斥）
4. 跟读：点句子右侧 🎙 直接录音（不播原句，避免把原声录进去）→「↺ 听我的」对比；设置里开「跟读达标才进下一句」后，低于 70 分停在这句重练，达标自动进下一句
5. **字幕搜索**：字幕区顶部搜索框，输入即过滤、回车跳到下一处命中
6. **引用即笔记**：句子右侧「引」按钮 → 把这句和**可点击的时间戳**写进 `{笔记目录}/粤语精听引用.md`，点时间戳跳回原句
5. 「**只看粤语**」隐藏英文讲解句，只留粤语句子（Fexingo 这种中英混排节目很有用）
7. 「存为精读笔记」生成带原文链接、粤拼生词表、笔记待填区的 Markdown

## 逐字稿从哪来

三层，逐级降级：

1. RSS 里的 `podcast:transcript`（Fexingo 全部 284 集都有）
2. 单集网页里指向 transcript 的链接（限同域名）
3. 都没有 → **本地转写**（SenseVoice，支持粤语，免费离线，20 分钟音频约 2 分钟）

Fexingo 的字幕是纯文本、没有时间轴。这种会在顶部提示「没有时间轴，点句不会跳转」，并给一个「**本地转写对齐时间**」按钮，跑一遍识别就能拿到真实时间。

## 本地转写（可选）

不配也能正常用——听、读、查词、跟读、笔记都跑得动，只是没字幕的节目不会有逐句文本。

配置在 `设置 → 本地转写`，三个文件放在同一个目录：

```
<识别目录>/
├── model.int8.onnx      SenseVoiceSmall int8，约 228 MB
├── tokens.txt           约 0.3 MB
├── silero_vad.onnx      约 0.6 MB
└── transcribe_yue.py    转写脚本（本仓库 extras/ 里）
```

需要一个装了 `sherpa-onnx` 和 `av` 的 Python 3.10–3.12，模型可从 `hf-mirror.com/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17` 取。

## 跟读录音与质量检查

录音会**自动裁掉首尾静音**（约 0.12 秒余量），转成 WAV 存到 `Cantonese/录音/`，
文件名是 `<节目id>-<年月日>-<时分秒>.wav`，
同目录下维护一份 `索引.md`（时间 / 节目 / 句子 / 时长 / 文件链接）。目录可在设置里改。

录音结束时会把麦克风参数写进 `cache/diag.log`：

```
录音结束 mime=audio/webm bytes=48211 时长=3.2s 采样率=48000 声道=1
         回声消除=true 降噪=true 自动增益=true
```

这几个参数本身就是音质问题的常见来源——例如回声消除会把弱读音吞掉，
自动增益会让音量忽大忽小。

所以录音默认走**原声采集**：`echoCancellation / noiseSuppression / autoGainControl` 全部关掉。
粤语的入声尾音（-t/-p/-k）最容易被回声消除吃掉，关掉后尾音才留得住。
如果录出来太轻，再去设置里关掉这个开关。

检查一条录音的质量：

```
python extras/check_rec.py 录音.wav --expect 1.4 --text "去边度食啊" \
    --jyutping "heoi3 bin1 dou6 sik6 aa3"
```

加上 `--jyutping` 会额外做**声调检查**：逐音节测基频，看**同一个声调的字音高是否一致**。
它不需要标准音的绝对音高，所以男女声、音量大小都不影响判断：

```
声调：
      音节      声调  音高      相对整句
      heoi3     3     206.5 Hz   -0.6 半音
      haa6      6     213.3 Hz   +0.0 半音
      sing4     4     207.8 Hz   -0.5 半音
      jat1      1     198.0 Hz   -1.3 半音     ← 第1声却读成了低平
      gaan1     1     250.0 Hz   +2.7 半音
      caan1     1     254.0 Hz   +3.0 半音
      teng1     1     242.4 Hz   +2.2 半音
声调提示（只作定位，不作评分）：
  ~ 「jat1」（第1声）比同声调的其它字低 3.8 个半音
```

**只给定位，不给分数。** 一个「78 分」无法指导行动，「这个字低了 3.8 个半音」可以直接改。
声调检查要求音节能切分出来（你念的时候字间有停顿）；切不开时会退化成「每段音高」，
不声称对应哪个字。

会输出格式、电平、信噪比、语音占比，并在给 `--text` 时做识别比对：

| 指标 | 健康范围 |
| --- | --- |
| 采样率 | ≥ 16000 Hz（建议 44100/48000） |
| 峰值 | −12 ~ −3 dBFS（高于 −1 就有削波风险） |
| RMS | −30 ~ −18 dBFS |
| 信噪比 | > 20 dB |
| 语音占比 | 40% ~ 90% |

偏离会直接列成「发现 N 个问题」，比如「音量太小：峰值仅 −39.0 dBFS」
或「削波：21.36% 的采样贴顶」。

## 错题本 / 易错词 / 打卡统计

### 错题本（句子级）

听不清、读不顺的句子，点句子右侧的 **⚑** 就进错题本；再点一次取消。

- 侧栏底部 **错题本 N** 打开清单，按时间倒序
- 每行三个动作：**▶ 原句**（跳回那一集并定位、高亮这句）、**✓ 过关**（归档）、**✕** 删除
- 「过关」的行会打上删除线，切到「全部」还能撤回
- 同一句反复标记只累加「标记 N 次」，不会产生重复条目
- 自动同步到 `{笔记目录}/错题本.md`（表格：句子 / 来自 / 标记次数 / 最近标记 / 状态）

### 易错词

生词本顶部有三个筛选：**全部 / 待复习 / 易错**。

- 复习时点「忘了」→ 记一次 lapse，词自动进「易错」
- 判定规则：答错 ≥2 次，或刚答错还没想起来（熟度 0）
- 易错列表按答错次数排序，行内显示「答错 N 次」
- 答对一次会暂时移出，但答错历史保留；再错就永久留在清单里

### 打卡统计

侧栏底部「连续 N 天 · 今日 X 分钟」点开，或点 **打卡**：

- 连续天数、今日时长
- 本月时长 / 本月篇数 / 累计时长 / 学习天数
- 最近 30 天柱状图（拖动进度条的时间不计入，只算真正播放的音频）
- 最近 12 周热力图（5 档深浅，每格一天）
- 本月时长自动换算成「几集节目 / 几趟京沪高铁」
- 常听节目排行（花时间最多的源）
- 24 小时收听生物钟环形图（晨读者 / 夜航者）
- 小发现：听得最久的一天、凌晨还在听哪一集、哪集听了不止一遍
- 底部汇总生词、易错词、错题数量

数据存在插件 `data.json`，同时每月写一份 `{统计目录}/YYYY-MM.md` 表格，方便在库里回看。

### 跟读打分

配好本地转写（SenseVoice）后，录完这句会自动识别，跟原句做**字级对齐**：

- 显示分数、对上几个字、「漏了哪些字」「多念了什么」
- 简繁差异、同音异体字（邊/边、嚟/来）按粤拼判定，不会因为写错字冤枉你
- 首句 3–6 秒（要加载模型），之后每句 1 秒左右；分数会记在「练 N」徽章旁
- 没配本地转写时这块不显示，其余功能照常用

### 错题连播

错题本里点「▶ 连播待过关」，只放这几句，一句接一句，不用回原集；点单行只放那一句。
每条错题都存了音频地址和起止秒数，即使那集被刷新挤出去了也能重听。

## 粤语发音（edge-tts）

点 🔊 时用微软的港式粤语音色合成，需要「本地转写」那一套 Python 环境，外加一个包：

```
pip install edge-tts
```

目录里要有 `tts_yue.py`（本仓库 `extras/` 里有），插件会以
`python tts_yue.py <输出> <音色>` 调用，正文从 stdin 传入。

三种音色，在设置里切换：

| 音色 | 声音 |
|---|---|
| `zh-HK-HiuGaaiNeural` | 女声，默认，最清晰 |
| `zh-HK-HiuMaanNeural` | 女声，略低沉 |
| `zh-HK-WanLungNeural` | 男声，接近播客男主播 |

**没配 Python 也能用**：会自动回落 Google TTS 的 `yue` 声道。但 Google 在境内经常超时，
建议配好 edge-tts。

合成一次约 1–3 秒，同词会缓存；双击字词时插件已在后台预取，点 🔊 通常立刻出声。

## 网络、权限与可选增强（社区目录披露）

### 网络请求：全部由你的操作触发，没有后台轮询

| 用途 | 目标 | 触发时机 | 是否送出文本内容 |
|---|---|---|---|
| 订阅刷新、单集正文抓取 | **仅你手动添加的** RSS / 网页地址 | 点刷新、打开文章 | 否 |
| 音频流 | 订阅源 `enclosure` 里的音频 CDN | 点播放 | 否 |
| 粤语发音（主用） | 本机 Python 调 `edge-tts`，文本发往微软语音服务 | 点 🔊 / 双击字词预取 | **是：选中的中文词句** |
| 粤语发音（兜底） | `translate.google.com/translate_tts` | edge-tts 不可用时 | **是：选中的中文词句** |
| 查粵典 | `words.hk`（用系统浏览器打开**外部链接**，插件本身不发请求） | 点「查粵典」 | 浏览器行为 |

- **点字查义完全离线**：粤语词典随 `main.js` 内置（见下），不联网。
- **本地转写完全离线**：SenseVoice 在你本机跑，音频不出本机。
- **没有**账号体系、付费功能、遥测、崩溃上报，也不做自动更新或自行安装依赖。
- 抓取到的网页正文会先经 `sanitizeHtml` 移除 `script/style/iframe/object/embed/form` 与所有 `on*` 属性、拦截 `javascript:` 链接，再写入阅读区。

### 关于「发音」的隐私提示

点 🔊 听粤语发音时，那一句中文会被送到**微软（edge-tts）**，失败时再送到 **Google**。如果你不希望任何文本离开本机，就不要点 🔊，直接听播客原声——粤拼、逐句字幕、查词、生词、错题、统计、录音全部不依赖这两个服务。

### 访问库（vault）之外的文件

启用本地转写 / edge-tts 后，插件（**仅桌面端**，`isDesktopOnly: true`）会通过 Node 的 `fs` / `child_process` 读取你在设置里填写的目录，并启动本地 Python 进程。这些路径**完全由你手动填写、默认留空**，插件不会自行创建、下载或扫描它们。除此之外，插件只读写 vault 内的笔记和 `.obsidian/plugins/pineapple-cantonese/` 下的缓存与可选数据文件。

### 市场安装只含三件套 —— 词典为什么照样能用

Obsidian 社区插件市场只会下载 `main.js`、`manifest.json`、`styles.css`。为了让「点字查义」开箱即用，**完整的 CC-Canto 词典（31,764 条）以 gzip 压缩后内置在 `main.js` 里**，运行时解压到内存，不产生任何网络请求、不写临时文件、不需要手动放置。

加载顺序：优先读插件目录下的 `dict-yue.json`（老用户手动放的完整词典，行为与以前完全一致）→ 读不到或文件损坏时用内置副本。设置页「可选增强状态」会显示当前用的是哪一份、多少词条。

社区政策禁止插件自动下载或安装依赖，所以内置是唯一既能保留功能又合规的做法：数据是随 release 分发的静态内容，不是运行时下载。

以下为**其余可选增强**，市场安装不含对应脚本，缺失时自动降级：

| 增强 | 需要的额外文件 | 缺了会怎样 | 如何启用 |
|---|---|---|---|
| 本地 SenseVoice 转写 | `extras/transcribe_yue.py` + 自备 Python / 模型 | 没有现成逐字稿的节目不会有逐句文本，其余功能照常 | 手工放置 |
| 常驻识别（跟读打分加速） | `shadow_server_yue.py` | 退回逐句单次转写，首句慢几秒；**打分功能不失效** | 手工放置 |
| edge-tts 粤语发音 | `extras/tts_yue.py` + 本机 `edge-tts` | 自动回落 Google TTS 的 `yue` 声道 | 手工放置 |

启用方式：从本仓库源码或 Release 附件取得对应 `.py`，**手动**放进 `.obsidian/plugins/pineapple-cantonese/`（脚本）或 `<识别目录>/`（模型），再到「设置 → 本地转写」填目录与 Python 解释器。插件不会自动下载或安装这些文件，也不会自动下载或安装任何依赖（含词典、模型与 Python 脚本）。

## 已知限制

- **粤语发音主用 edge-tts**（需要 Python 环境，见下节），失败时回落 Google `tl=yue`；两者都不通才会报错，原声与粤拼不受影响
- 部分「粤语教学」播客其实是 AI 生成的，中文用普通话 TTS 朗读。插件会在订阅分组里标出来，并在打开这类节目时显示提示条
- RTHK / BBC 粤语 / buzzsprout 在大陆多数网络连不上
- 粤语没有官方书面正字规范，同音异写很常见（例：呢/哩），词典按常用写法收录
- Fexingo 那档节目的中文原声是普通话，插件无法改变源音频，只能另给粤语 TTS

## 上架与发布规范（维护者笔记）

本插件在 Obsidian 社区目录登记为 **Pineapple Cantonese Listening**；界面内的中文名「菠萝粤语精听」保持不变。

与同作者的 `pineapple-english` **不是同一插件的重复提交**：两者共享界面骨架，但语言管线完全不同（粤拼自动标注 / 中文最长匹配切词 / CC-Canto 词典 / SenseVoice 识别 / 港式粤语 TTS / 粤语播客源），目标用户与内容源不重叠，差异见开头「和英文版的区别」。

- **版本事实来源**：默认分支 HEAD 的 `manifest.json`；`versions.json` 记录每个历史版本对应的最低 Obsidian 版本；`package.json` 的 `version` 必须与 manifest 一致。
- **打 tag**：严格 `x.y.z`，**不带 `v`**。用 `node version-bump.mjs 1.2.1` 一次同步三处版本文件，提交后再 `git tag 1.2.1 && git push origin 1.2.1`。
- **Release 附件**：只放 `main.js`、`manifest.json`、`styles.css` 三件；`.github/workflows/release.yml` 会校验 tag 与 manifest 版本一致并自动生成 Release。`dict-yue.json` 与 `extras/*.py` **留在仓库源码里**供用户手动获取，但不作为市场安装附件。
- **无构建步骤**：`main.js` 既是源码也是产物（词典以静态压缩数据内联，见上文），仓库文件与 Release 附件逐字节一致。
- **仓库卫生**：`.gitignore` 已排除 `data.json`（私人学习数据）、`data.json.bak`、`cache/`、`backups/`、录音、`*.onnx` 模型与本地打包产物。提交前请确认这些文件没有进入公开仓库。
- **首次提交流程**：注册并登录 `community.obsidian.md` → Profile 连接 GitHub（只读授权）→ Plugins → New plugin 填仓库地址 → 自动审核 Scorecard 的 error 清零 → Publish。之后每次更新只需发新 Release，目录会自动同步到客户端的社区插件列表。
